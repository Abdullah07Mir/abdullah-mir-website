Industry experience

I analysed datasets of 300K+ records in Python with Pandas and NumPy, benchmarked five classification models (Logistic Regression, Random Forest, XGBoost, LightGBM and CatBoost) on an imbalanced binary problem, and built Power BI dashboards that turned model outputs into clear insight for non-technical stakeholders.

Methods

Imbalance-aware machine learning.

  • Classification with Logistic Regression, Random Forest, XGBoost, LightGBM and CatBoost, using cross-validation and hyperparameter tuning.
  • Evaluation with ROC-AUC, F1 and recall instead of accuracy alone, so a model is judged on the minority class it needs to find.
  • Reproducible preprocessing and feature engineering pipelines in Python and scikit-learn.
  • SQL and NoSQL: querying and optimising databases, and T-SQL in SQL Server.
  • Big data with Spark, Databricks and MLflow.
  • Power BI dashboards for non-technical stakeholders.
